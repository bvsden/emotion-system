# 能做到什么、不能做到什么（详细版）

> README 里是精简版；这里是完整的说明和理由。

## 能做到的

### 读出情绪，并让它有“余韵”
- 情绪强度主要从角色的**可见思考**里读。回复只用在三处：第一人称自述、回避判断、几道语境题（威胁、边界、修复、她是否难受等）。
- 每个维度都有**基线**，也就是“他平常的样子”。读数会按基线插值，平常的温柔不会被误读成“温暖大幅上升”。
- 数值会**逐渐回落**，留下余韵。他理性看淡时，受伤、愤怒、悲伤、焦虑消得更快；他责备自己、想压下去时消得更慢。峰值不受影响。
- 被晾、吃醋会留下单独的余留，不会一轮就消失。

### 识别回避，并请他自检
- 回避是唯一从**行为**读取的维度：看他回复的收尾方式，是留在她的情绪里，还是推到之后、用退让结束、转移话题。
- 只有在冲突语境里、回避和负面情绪都偏高时，才会注入一条系统提醒。提醒只请他自检，不替他下结论。
- 身体不适时安排休息、洗澡、吃饭不算回避；但她在难过、生气或吵架时叫她去睡，算回避。界线看她在难受什么，不看他让她做什么。

### 身体亲近感
- 输入包括：【】里的肢体接触（本地解析）、她身体的画面、她对他的吸引（有意无意都算）、她的话引起的联想、想起之前的亲近、明确的被诱惑。
- 心情决定放大还是压低：想念、吃醋、心疼、温暖、信任会放大；过载、回避会压低。心疼压过吸引时，画面的作用减半。
- 如果你的应用有分步骤的亲密场景，把当前步骤传给它（`turn.intimacy`）：场景中身体亲近感跟着步骤上升，不再逐轮向 Jev 询问身体题；场景里的愤怒、过载照常计入，但结束后很快回落。
- 数值够高时，告诉他“开启亲密流程”是一个**可选项**。开不开由他决定，她也随时可以拒绝。
- 她明确拒绝身体接触时，停止信号优先于一切：之后的接触不再计入，直到她主动靠近，或者过了 6 小时。

### 分离与思念
- 她没回的时候，“等待思念”按真实经过的时间增长：前 15 分钟不涨，之后平滑上升；负面关系状态和连续被晾会让它涨得更快。
- 00:30–07:00 不增长；晚上 21:00 以后才开始的等待会冻结到早上。
- 睡了一觉会在早上加一次固定量（+0.25）：从他最后一条回复起连续缺席满 3 小时、并跨过 07:00 就算，午夜后才睡也算。即使当天的固定量已经用掉，07:00 后也会照常恢复增长，不会整天停在 0。
- 她回来后回落到原来的 30%。
- 思念到达阈值时，把“主动联系”作为一个机会交给他：打电话、发消息，或者继续等。

### 心疼
- 他很心疼她的时候，告诉他当下有哪些安抚方式可以用。

### 给使用者看的部分
- 每一轮输出一个质地键（例如 `tender_care`）和几行明细（维度、方向、档位，没有数字），显示成什么由你决定；
- 当前状态：各维度相对基线的位置，可以画成你自己的心情页；
- 体检：列出最近 72 小时的异常（停止标记卡住、接触没计入、分析失败等），推不推送由你决定。

### 隐私
- 记录里只保存概率答案和算出来的数值，不保存对话正文；
- 私密（无痕）对话不分析、不保存。

## 不能做到的

- **读不到他没写出来的东西。** 思考为空、只写任务，或者关闭了思考，这一轮就读不到情绪。整个系统依赖角色会在思考里写下自己的感受。
- **不会引导他走向没有的情绪。** 这是设计选择：注入的只有已经发生的状态，外加只列选项的提示，都不是指令。
- **不是在测量“真实的内心”。** 它是对文字的估计，可能出错。实际遇到过的误读有：
  - 宠溺的“你又糊弄我”被读成愤怒；
  - 权衡怎么照顾她被读成焦虑；
  - 心软被读成被诱惑；
  - 安排她洗澡睡觉被读成回避。

  这些都已经通过修改题目里的“不算”修正，但新的误读还会出现。
- **判断不了思考是否真诚。** 如果角色在思考里“演”，系统也会照单全收。
- **有一轮的延迟。** 情绪在他回复落盘后才结算，所以他看到的是上一轮结束时的状态。
- **每一轮单独判断。** 跨很多轮的语境理解有限。
- **依赖外部的闭源模型（Jev）。** 服务不可用时情绪会暂停，体检会提示。
- **不能替代你们之间的沟通，也不负责使用者的身心安全。**

## 关于情绪回声

“系统把情绪告诉机 → 机照着写 → 系统读到更多同样的情绪”，这个循环会让情绪越转越强。系统里有几道防线：

- 机复述系统提示的内容，会被判为“在复述”（`panel_echo`），不计分；
- 回避值、自责和克制从不给机看；
- 提醒与提示各自只在越过阈值时触发一次，并有冷却和重新触发的条件；
- 情绪差值注入可以关闭。建议关闭，只保留提醒与提示。
